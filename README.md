# AI Business Intelligence Assistant 🤖

## Project Overview
The AI Business Intelligence Assistant is a data analytics and machine learning project designed to help businesses understand their sales performance, generate insights, and make data-driven decisions.

This project uses Python, data analysis, Google's Gemini AI, and Machine Learning to analyse Superstore sales data and predict future sales.

## Objectives
- Analyse overall sales and profit performance.
- Identify top-performing product categories and regions.
- Generate automated business insights using AI.
- Build an AI chatbot to answer business-related questions.
- Predict monthly sales using Machine Learning.
- Evaluate prediction performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Gemini AI
- Scikit-learn
- Jupyter Notebook

## Project Features

### 1. Exploratory Data Analysis (EDA)
- Total Sales and Profit Analysis
- Category-wise Sales Analysis
- Region-wise Sales Analysis
- Monthly Sales Trends
- Customer Analysis

### 2. AI Business Insights
Used Google Gemini AI to generate business insights and recommendations based on sales data.

### 3. AI Business Chatbot
Developed an AI chatbot that answers business questions using the Superstore dataset.

### 4. Automatic Business Insights
Generated automated business performance summaries and recommendations.

### 5. Sales Prediction
Built a Linear Regression model using Scikit-learn to predict monthly sales.

Added monthly seasonality features to improve prediction performance.

## Machine Learning Model Evaluation

| Metric | Initial Model | Improved Model |
|---|---:|---:|
| Mean Absolute Error (MAE) | 25,585.30 | 13,649.87 |
| R² Score | -0.892 | 0.242 |

The improved model achieved a lower prediction error after adding monthly seasonality features.
